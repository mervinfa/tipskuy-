## Deskripsi Karya
Latar Belakang
Mobilitas masyarakat antar kota saat ini sangat tinggi, baik untuk urusan pekerjaan, pendidikan, maupun wisata. Di saat yang bersamaan, tren Jasa Titip (Jastip) dengan kebutuhan pengiriman barang yang cepat dan terjangkau juga terus meningkat. Sayangnya, layanan Ekspedisi seringkali memakan waktu berhari-hari dan memiliki tarif tetap yang kadang memberatkan untuk barang-barang tertentu. Di sisi lain, banyak pelaku perjalanan yang berkendara antar kota dengan ruang bagasi kosong yang tidak dimanfaatkan. Ruang kosong ini sebenarnya adalah potensi ekonomi yang belum terjamah.

Tujuan
Tipskuy! dibangun untuk menjadi solusi penengah (marketplace) yang menghubungkan pihak penitip barang dengan pihak pelaku perjalanan yang memiliki rute dan jadwal yang searah. Mengadaptasi konsep seperti Gojek namun difokuskan pada jastip antar kota, Tipskuy! bertujuan untuk menciptakan ekosistem pengiriman yang saling menguntungkan, aman, dan fleksibel.

Manfaat
Bagi Driver: Memberikan peluang side-income (pendapatan tambahan) untuk menutupi biaya operasional perjalanan seperti bensin atau e-toll hanya dengan memanfaatkan ruang kosong di kendaraan mereka (Take Job).

Bagi Pengguna (Penitip): Mendapatkan layanan pengiriman atau jastip yang jauh lebih cepat (hari itu juga tiba / same-day delivery) dengan tarif yang lebih dinamis dan bersahabat berkat fitur Negosiasi Harga.

Bagi Masyarakat: Membentuk komunitas yang saling membantu dan secara makro membantu mengurangi jejak karbon (carbon footprint) dengan mengoptimalkan kendaraan yang sudah pasti berangkat, alih-alih menambah armada logistik baru di jalan raya.

Pemilihan Subtema
Karya ini mengimplementasikan tema INNOVATE dengan mengangkat subtema Ekonomi. Pemilihan subtema ini dilandasi oleh kemampuan Tipskuy! dalam melakukan Optimize (mengoptimalkan) sumber daya yang sudah ada (ruang kosong di kendaraan) untuk menciptakan peluang ekonomi digital baru berbasis sharing economy. Melalui Advance Technological Endeavors, Tipskuy! mentransformasi budaya titip-menitip tradisional menjadi sistem yang terstruktur, tervalidasi, dan mampu meningkatkan kesejahteraan penggunanya.

Fitur Unggulan Sistem:
1. Forum & Request yaitu Wadah komunitas untuk memposting permintaan titipan ke kota tertentu.
2. Sistem Negosiasi Harga digunakan untuk tawar-menawar harga yang adil (win-win solution) antara penitip dan pengantar.
3. Live Progress Tracking adalah Pemantauan status barang secara real-time ("Sedang Dikirim", "Menuju Tempat", "Paket Tiba").
4. Sistem pembayaran terpusat (Transfer, E-Wallet, QRIS) dan fitur obrolan langsung (Chat Driver) untuk menjamin keamanan transaksi.

## Getting Started

## Cara Menjalankan Project di Local (Local Development)

Untuk menjalankan Website Tipskuy! di komputer Anda, pastikan **Node.js** sudah terinstal. Kemudian, ikuti langkah-langkah berikut:

1. Ekstrak file `.zip` project ini dan buka foldernya menggunakan *code editor* (seperti VS Code).
2. Buka Terminal di dalam folder project tersebut.
3. Jalankan perintah instalasi berikut untuk mengunduh semua *dependencies* (termasuk Next.js, Tailwind, `react-icons`, dan `lucide-react`). Kami menyarankan menggunakan *flag* `--legacy-peer-deps` agar tidak terjadi *error* bentrok versi antar *library* ikon:

   ```bash
   npm install --legacy-peer-deps

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
